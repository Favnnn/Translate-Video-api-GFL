# Переводчик субтитров с экрана (Vid)

Программа смотрит видео, находит субтитры на экране, распознаёт их, переводит на
русский и делает озвучку с приглушением оригинального звука. На выходе —
готовый файл `<имя>_озвучка.mp4`.

Работает с любым видеофайлом (mp4/mkv/avi — всё, что открывает ffmpeg) и с
длинными видео (7+ часов — проверено): микширование потоковое, память не растёт
от длины видео.

## Как пользоваться

**Способ 1 (основной):** перетащите видеофайл мышкой на файл
`Озвучить видео.bat` — откроется консоль с прогрессом, в конце появится:

- `Output\<имя>_перевод.txt` — субтитры EN/RU (UTF-8)
- `Output/<имя>_озвучка.mp4` — видео с русской озвучкой

**Способ 2 (командная строка):**

```
cd /d "%~dp0app"
python analyze_video.py "путь\к\видео.mp4"
```

## Как это работает (этапы)

1. **Скан** — по кадрам ищутся интервалы, где в зонах титров есть текст
   (доля белых/ярких пикселей, гистерезис порогов, склейка коротких кусков,
   «добор» слабых сегментов). Параллельно по ядрам CPU.
2. **OCR** — EasyOCR (GPU) распознаёт текст в найденных окнах, каждая точка
   кадрируется с несколькими вариантами обрезки/увеличения.
3. **Перевод** — Google-переводчик, несколько одновременных запросов.
4. **Озвучка** — edge-tts (голос ru-RU-SvetlanaNeural по умолчанию), фразы
   синтезируются параллельно.
5. **Микс** — ffmpeg декодирует оригинал блоками по 2 секунды, фон приглушается
   под голосом (огибающая с атакой/спадом), голоса накладываются, лимитер
   `bg_limit`, результат сразу кодируется в итоговый mp4.

- Бары — в стиле `pip install` (rich): синяя линия, `сделано/всего`, скорость,
  `eta`. «Готово время» — длительность этапа.
- **добор** — сегменты, найденные по сниженному порогу между основными
  (короткие/бледные надписи, например «15.»); каждый проверяется OCR:
  принимается только уверенный текст.
- В лог-файлах (вывод не в консоль) бары упрощаются до ASCII `[=====>-----]`.

## settings.json

Все настройки — в `Vid\settings.json`, применяются при старте программы.

| Группа | Ключи | Что делают |
|---|---|---|
| Область поиска | `roi_titles`, `roi_center`, `roi_speaker` | прямоугольники зон с текстом (для 1920×1080) |
| Детекция титров | `white_thr`, `wr_on`, `wr_off`, `off_hold_sec`, `min_segment_sec`, `merge_gap_sec` | порог белого, пороги появления/исчезновения, анти-мигание |
| Уточнения | `median_win`, `backtrack_sec` | медианный фильтр, отступ назад при появлении текста |
| Добор | `gap_wr_thr`, `gap_min_sec`, `gap_min_conf` | сниженный порог для слабых сегментов + фильтр уверенности |
| Центр. зона | `black_frame_thr`, `bright_thr`, `cz_wr_on`, `cz_wr_off`, `dim_text_thr` | включается только на тёмных кадрах (титры по центру) |
| Зона спикера | `wr_on_c`, `wr_off_c`, `spk_on` | свой порог для нижней зоны |
| OCR | `ocr_point_step`, `ocr_point_window`, `ocr_end_offsets`, `ocr_end_window`, `ocr_edge_pad`, `ocr_mag`, `ocr_min_conf` | плотность точек распознавания, варианты кадрирования, увеличение, фильтр уверенности |
| Перевод | `translate_sleep`, `translate_retries`, `translate_concurrent` | пауза между запросами, повторы при ошибках, одновременные запросы |
| Озвучка | `tts_enabled`, `tts_voice`, `tts_rate`, `tts_pitch`, `tts_adaptive`, `tts_rate_max`, `voice_gap`, `tts_concurrent` | голос, темп, пауза между фразами, одновременные запросы |
| Микс | `orig_volume`, `bg_limit`, `duck_volume`, `duck_attack`, `duck_release`, `duck_hold`, `mix_sr` | громкость фона, потолок фона, глубина приглушения, форма огибающей |
| Производительность | `parallel`, `hw_decode`, `scan_workers`, `ocr_workers`, `ocr_batch` | параллельные режимы; `0` = автоматически |
| Вывод | `output_dir` | папка результатов (по умолчанию `Output`) |

## Переменные окружения (для отладки)

| Переменная | Действие |
|---|---|
| `DSH_DEBUG=1` | печатать список сегментов (с пометкой «(добор)») и применённые настройки |
| `DSH_CONSOLE=1` | принудительно включить цветные бары (батник ставит сам) |
| `DSH_HW=1` | аппаратное декодирование NVDEC (по умолчанию выкл: меняет цвета и ломает пороги детекции) |
| `DSH_PARALLEL=0` | отключить параллельные режимы |
| `DSH_SCAN_WORKERS`, `DSH_OCR_WORKERS` | ручное число воркеров скана/OCR |
| `DSH_OCR_BATCH` | размер батча EasyOCR |

## Требования

- Windows, Python 3.10+ с пакетами: `easyocr`, `edge-tts`, `numpy`, `opencv-python`
- NVIDIA GPU с CUDA — для OCR (иначе OCR пойдёт на CPU, медленно)
- `ffmpeg` в PATH
- Интернет — для перевода и синтеза речи

## Особенности

- Аппаратное декодирование (NVDEC) по умолчанию **выключено**: оно слегка
  меняет цвета кадров, из-за чего сдвигаются пороги детекции и теряются фразы.
- Перевод — это живые запросы к Google: формулировки RU могут отличаться
  от дня ко дню (EN-строки при этом распознаются стабильно).
- Временные файлы этапов кладутся в системную временную папку и удаляются
  сами; финальные файлы — только в `Output\`.
